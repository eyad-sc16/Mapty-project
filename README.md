# Mapty // Map Your Workouts 🗺️🏃‍♂️🚴‍♀️

Mapty is a feature-rich, interactive web application designed to log, track, and map running and cycling workouts. Built as part of an advanced JavaScript course and enhanced with modern UI components and custom features.

---

## ✨ Features

- **Geolocation Integration**: Automatically detects and centers the map on your current location.
- **Interactive Workout Logging**: Click anywhere on the map to add a new running or cycling workout.
- **Advanced Metrics**: Automatically calculates and displays Pace (min/km) for running and Speed (km/h) for cycling, along with distance, duration, cadence, and elevation gain.
- **Persistent Storage**: Saves all workouts in browser `localStorage` so your data persists across page reloads.
- **Workout Management**:
  - **Edit Workouts**: Easily modify existing workout details.
  - **Delete Workouts**: Remove individual workouts (with map marker synchronization).
  - **Reset All**: Clear all workouts and drawings on the map in one click.
- **Map Drawing Tools**: Integrated Leaflet.Draw controls to draw and label shapes (Polygons, Lines, Circles, Rectangles) on the map.
- **Sorting & Filtering**: Quickly sort workouts or view all markers.
- **Modern UI & UX**:
  - Smooth sidebar open/close animations using CSS transitions.
  - Pure CSS hover tooltips in English for all action buttons.
  - Fully responsive and polished dark-themed interface.

---

## 🛠️ Tech Stack

- **HTML5** & **CSS3** (Flexbox, CSS Grid, Custom Properties, Pure CSS Tooltips)
- **Vanilla JavaScript (ES6+)** (Object-Oriented Programming with ES6 Classes)
- **Leaflet.js** & **Leaflet.Draw** (Interactive mapping library)

---

## 🚀 Getting Started

1. Clone or download the repository to your local machine.
2. Open `index.html` using a live server (such as VS Code's **Live Server** extension) or directly in any modern web browser.
3. Allow location access when prompted by your browser to initialize the map.
